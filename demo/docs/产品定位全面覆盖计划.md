# AI通识培训平台产品定位全面覆盖计划

> 计划版本：1.1  
> 确认日期：2026-07-31  
> 实施状态：前置、L1、L2、L3、L4 已于 2026-07-31 完成高保真 Demo 范围验收  
> 主定位：教学 Learning OS  
> 交付边界：单页高保真 Demo、确定性模拟数据、不连接生产服务

## 1. 目标与完成定义

产品按四个定位层级逐步补齐：

1. **L1 师生教学 Learning OS**：教师和学生围绕课程完成教、学、测、评与补学回流。
2. **L2 教师成长、实训与研究**：教师个人学习、真实教学应用、自由实训和研究成果进入统一能力证据。
3. **L3 学校教学运行管理**：教学管理者查看聚合与匿名数据，发现问题、交办教师并跟踪干预结果。
4. **L4 可信 AI 与跨流程治理**：统一来源、权限、匿名、置信度、人工复核、版本和审计记录。

每项能力使用同一五级覆盖标准：

| 等级 | 含义 |
| --- | --- |
| 1 | 未规划 |
| 2 | 已有信息架构 |
| 3 | 已有页面与模拟数据 |
| 4 | 已形成可交互闭环 |
| 5 | 已具备证据、权限、回流和自动化验收 |

只有同时具备对象入口、角色化任务、可变状态、证据结果、下一步回流和自动化验收，才认定为 5/5。

## 2. 实施顺序

### 前置：文档与工程基础

- 保存本计划和动态覆盖矩阵。
- 将教师、学生、教学管理者锁定为三类最终用户。
- 保持单页状态驱动，不引入路由或第二套视觉系统。
- 拆分低频角色工作区并使用懒加载，控制初始包体。

### L1：完整师生教学闭环

- 以 `courseId` 隔离课程、班级、任务、测评、报告、练习和补学状态。
- 保留“生成式视觉设计”完整主闭环。
- 将“AI 创作伦理与安全”补为“导学 → 学习 → 测评 → 报告 → 补学”的轻量副闭环。
- 新增统一 AI 证据抽屉，替代只显示提示的证据操作。
- 学生报告只呈现个人变化、证据和下一步，不呈现班级排名与其他学生数据。

### L2：教师能力证据闭环

- 从现有 JSON 唯一题库选取 C02、C05、C34、C09、C39、C171，形成可真实作答的精简摸底包。
- 将课程学习、自由实训、智能备课、AI 批改、分层干预、AI 研究和复测统一记录为教师能力证据。
- 教学成果进入个人成长报告，但个人答案、笔记、计划和研究草稿不向教学管理者开放。

### L3：学校教学运行管理

- 新增独立“教学管理”角色和任务首页。
- 工作区固定为运行总览、课程班级、学习质量、测评运行、AI 应用。
- 管理者查看全校、人工智能学院、数字创意学院的聚合数据和匿名学生明细。
- 主预警闭环为“负向提示词掌握度 54% → 管理者交办 → 教师干预 → 学生完成 → 预警关闭”。

### L4：可信治理

- 所有关键 AI 结果统一记录来源、权限范围、匿名状态、版本、置信度、证据充分度、人工复核和修改时间。
- 教师、学生、管理者使用集中权限规则。
- 证据不足必须明确标记；低置信度进入人工复核；AI 原值与人工最终值同时保留。
- 所有关键状态变化进入可见模拟审计记录。

## 3. 状态与接口方向

- `UserRole` 扩展为 `teacher | student | manager`。
- 新增 `ManagerWorkspaceTab`、`ManagerSelection`、`TeachingOperationAlert`。
- 新增 `CourseRuntimeBundle`，按课程隔离教学运行数据。
- 新增 `EvidenceRecord` 与 `TeacherGrowthEvidence`。
- 学生补学完成同时更新教师教学过程和管理预警。
- 重置演示恢复三角色、两课程、四类预警和治理状态。

## 4. 验收

每个层级作为独立交付单元，必须完成：

- 对应组件与状态测试。
- `npm run typecheck`。
- `npm test -- --testTimeout=10000`。
- `npm run build`。
- 1440×900 与 390×844 真实浏览器验证。
- 唯一 H1、无横向溢出、关键操作无遮挡、控制台 0 error/0 warning。
- 同步更新 `AGENTS.md`、`README.md`、`PROJECT_STATUS.md` 和覆盖矩阵。

## 5. 明确边界

- 教学管理者只管理教学运行，不进入教师培训项目、教师个人成长或研究配置。
- 管理者可查看匿名学生明细，不查看实名、联系方式、原始个人作品或个人报告。
- 治理作为跨流程能力，不新增平台管理员角色。
- 不接真实组织权限、数据库、大模型、文件上传、考试防作弊或第三方工具。
- 未接真实服务的部分标记为“高保真模拟边界”，不计为产品定位缺失。
