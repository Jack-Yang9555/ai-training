# 三套差异化平台 Demo

三套方案共用教师成长、五维能力、三项可信门槛和 L1—L4 的业务底座，但面向不同决策者、使用场景与核心任务。每套包含 12 个可独立打开的单文件 HTML，页面间通过各自导航互相跳转，不依赖外部样式、脚本或图片。

| 目录 | 平台定位 | 主要用户 | 核心功能 | 视觉方向 |
| --- | --- | --- | --- | --- |
| `demo01/` | **AI 教师成长学院** | 一线教师、导师、教师发展中心 | 个体成长诊断、导师制研修、同伴学习、课堂实践复盘、长期成长档案 | 温暖学院派：深青、陶土橙、纸张米色、宋体标题、克制边框 |
| `demo02/` | **可信 AI 能力认证中心** | 学校管理者、认证专员、质量负责人 | 结构化证据台账、四通道取证、三项门槛判定、L1—L4 正式认证、审计追溯 | 深色认证控制台：海军蓝、荧光青、规则网格、侧栏导航、方形组件 |
| `demo03/` | **AI 教学创新工场** | 创新教师团队、教研组、项目负责人 | 真实项目挑战、快速原型共创、课堂试飞、研究实验、作品集与成果路演 | 创新工场风：荧光绿、电紫、珊瑚橙、粗描边、硬阴影、冲刺看板语言 |

## 推荐比较路径

每套依次打开以下页面即可快速看出定位差异：

1. `01-*`：平台总览与核心叙事。
2. `02-*`：摸底或挑战如何开始。
3. `03-*`：能力结果如何表达。
4. `06-*`：实训、取证或原型生产方式。
5. `09-*`：成长档案、认证复测或作品集收口。
6. `10-*`：组织端如何查看教师发展。
7. `12-*`：事实核验、数据版权和人工责任三项门槛。

## 方案边界

- 当前为静态高保真概念 Demo，业务数据均为虚构模拟数据。
- 顶部或侧边导航可在同一套方案的 12 个 HTML 之间切换。
- “查看学院方案 / 查看认证逻辑 / 打开工场任务书”可展开本方案的核心定位说明。
- 三套方案用于比较产品路线，不代表必须拆成三套生产系统；正式开发可选择其中一套作为主视觉和信息架构基线。
