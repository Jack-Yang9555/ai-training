## 维护约定

1. `demo/docs/` 只保存 Demo 产品定位、覆盖矩阵和平台总览。
2. 本目录保存可继续编辑的源文件及需版本管理的 Word 交付文件；临时 Word 与 PDF 导出放入 `output/word` 或 `output/pdf`。
3. 题库以 `课程与测评/data/高职教师AI认知测评题库.json` 为唯一数据源，生成型 Markdown 和 HTML 通过 `scripts/测评题库/` 维护。
4. 历史脚本和退出当前工作流的版本移入 `archive/`，不再使用“副本”“最终版”等含义不清的名称。
