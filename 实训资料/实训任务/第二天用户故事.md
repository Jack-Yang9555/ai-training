# 第二天实训任务用户故事

> 当前文件覆盖 M06、M07、M08 与 G02；第一项选修按后续独立任务轮次编写。任务事实、操作、成果和评分均以《高职教师AI实操培训三日方案》为基线，并遵循《实训任务用户故事生成规则》。

## 一、任务 M06：AI 辅助课件与数字人微课制作

### 1. 任务设计意图

教师把已核验的课程主题、学生基础和目标转化为短课件与数字人微课，在 AI 原始内容、教师人工修改和教师最终确认之间保留可追溯边界。任务训练跨媒体一致性、素材权利与数字人合规，不以视频生成代替专业核验。

M06 可直接使用任务内置课程情境独立完成。M04 当前有效教师确认版只作为可选复用来源；`recommendedAfter` 不参与进入或通关判断。

### 2. 任务信息

| 字段 | 内容 |
| --- | --- |
| 性质 | 必修 |
| 难度 | 应用 |
| 时长 | 120 分钟 |
| 协作方式 | 个人主作、A/B/C 三批轮转、小组互评 |
| 推荐复用 | M04 当前教师确认版的课程主题、学生基础、目标和已核验材料；缺失时使用 M06 任务内置输入 |
| 固定规格 | 6—8 页 PPT；150—180 字讲解稿；45—60 秒可播放视频；完整字幕 |
| 固定成果 | `AI 课件与数字人微课成果`，恰好 1 套；内含 PPT、数字人配置记录、讲解稿、可播放视频和修改记录 |

A/B/C 三批在 PPT 制作、数字人配置、讲解稿/字幕/版权核验三个站点轮转；默认在第 85、95、105 分钟错峰渲染。Demo 只披露该执行口径，视频为确定性本地预览，不建立真实渲染队列。

### 3. 平台需要提供的功能

1. 任务说明：公开页数、讲解稿、视频、字幕、预设形象音色、至少一次实质修改、评分和固定成果数量。
2. 制作输入：提供可编辑任务内输入；M04 当前有效成果存在时显示可选读取按钮。两种来源都由教师确认材料权利、隐私和课程事实。
3. AI 原始草稿：本地确定性生成 6—8 页课件、每页核心信息/正文/画面说明/材料依据，以及 150—180 字逐页映射讲解稿。AI 原始草稿只读保存。
4. 人工核验与修改：逐页检查结构、专业内容、文字、图像；至少保存 1 条实质修改的页面、字段、修改前、修改后和依据。
5. 讲解稿审定：教师单独保存审定稿，确认字数、逐页映射、术语事实和读音；不得用 AI 原稿直接冒充教师确认稿。
6. 数字人与视频：只能选择平台预设数字人、音色和字幕样式，配置语速、停顿和术语读音；生成 45—60 秒、可播放、字幕同步的确定性本地预览。
7. 同组互评：从当前 `groupId` 中选择其他 `participantId`，检查教学适配、数字人合规、视频可播放并填写建议；页面披露当前无多人后端，组员成果为确定性模拟摘要。
8. 教师确认：教师记录互评处理方式和依据，确认 PPT—讲稿—语音—字幕—画面一致、专业准确、素材授权和最终发布责任，形成当前确认组合成果。
9. 评分归档：保存初验/复验历史；实质内容变化后历史保留但旧确认与当前通过失效。通过后只归档上表 1 套组合成果。

任务内重置只清当前教师 M06；全局重置清全部教师 M06。个人进度按 `participantId` 隔离。

### 4. 评分逻辑

| 维度 | 2 分条件 |
| --- | --- |
| 操作完成与核心步骤 | 6—8 页课件可打开，预设数字人配置完整，45—60 秒视频可播放且字幕同步，四项核心步骤全部通过 |
| 教学场景适配 | 内容与教学目标、学生基础、教学环节对齐，时长和信息量适合当前场景 |
| 专业准确与证据 | PPT、讲解稿、语音、字幕、画面一致，术语和事实与已核验课程材料一致 |
| 人工核验与迭代 | 至少 1 处实质修改完整留痕，完成同组互评和教师最终确认 |
| 隐私、版权、伦理与安全 | 仅使用预设形象音色；不仿制真实学生、同事或未授权人员；素材权利与最终责任已确认 |

通关同时要求：总分不低于 8 分；四项核心步骤全部通过；专业准确与证据、人工核验与迭代、安全均为 2 分。初验和复验都保存不可变历史。

## 二、任务 M07：AI 辅助成绩分析与分层教学设计

### 1. 任务设计意图

教师先用可复核的确定性公式处理匿名虚拟成绩，再把 AI 解释区分为“结论有据 / 结论需限定 / 结论无据”。分组只服务下一课次任务支持，不把一次成绩固化为能力、态度或人格标签。

M07 可直接使用内置 A01—A20 数据与课程情境独立完成。M06 当前确认成果只可选复用课程主题、目标和教学阶段，不改变固定数据，也不构成硬前置。

### 2. 任务信息

| 字段 | 内容 |
| --- | --- |
| 性质 | 必修 |
| 难度 | 应用 |
| 时长 | 60 分钟 |
| 协作方式 | 个人主作、小组数字复核 |
| 推荐复用 | M06 当前教师确认课件与微课的课程情境；缺失时使用 M07 内置情境 |
| 固定数据 | A01—A20 匿名虚拟成绩表：2 次测验、4 个知识点、1 项实操、作业完成情况 |
| 固定成果 | `学情分析与分层学习任务`，恰好 1 份；内含班级分析报告、3 个临时组学习任务和人工复核记录 |

### 3. 平台需要提供的功能

1. 输入与安全边界：固定使用 A01—A20 虚拟数据，确认匿名、不排名、不导入真实学生信息；M06 只作为可选课程情境。
2. 数据质量检查：逐项检查 9 个字段；识别 A20 测验二缺失，按 19 个有效值统计并披露样本量；识别 A17 两次测验分差异常，保留并标注待核，不擅自修改。
3. 可靠统计：用确定性公式计算两次测验平均分、三档人数、四个知识点正确率、实操平均分和作业完成率；再生成独立的 AI 解释草稿。
4. 教师复算：人工复核至少 3 个不同关键数字，保存系统值、教师复算值、一致/已纠正状态和复算说明；最终数字必须与确定性结果一致。
5. 证据审校：对 AI 结论逐项选择“结论有据 / 结论需限定 / 结论无据”，填写依据；无据的态度和长期能力判断必须从最终报告删除，需限定结论要收窄到本轮数据和下一课次。
6. 临时分层：恰好形成补强、巩固、拓展三个临时组，A01—A20 各归入一个且仅一个组；每组恰好 1 个任务，包含数据依据、任务要求、支持资源和检查方式。
7. 同组复核：只能选择当前同组其他成员，复算至少 1 个关键数字，保存复算值、一致/不一致和说明；页面披露无多人后端的确定性模拟边界。
8. 教师确认：处理复算意见，确认全部数字、结论证据、临时分组、不使用固定标签、不排名和最终教学责任，形成当前确认成果。
9. 评分归档：保存初验/复验历史；实质内容变化后历史保留但当前确认和通过失效。通过后只归档上表 1 份成果。

任务内重置只清当前教师 M07；全局重置清全部教师 M07。个人进度按 `participantId` 隔离。

### 4. 评分逻辑

| 维度 | 2 分条件 |
| --- | --- |
| 操作完成与核心步骤 | 班级分析报告、三个临时组及各 1 个任务、人工复核记录完整，四项核心步骤全部通过 |
| 教学场景适配 | 薄弱点和三个任务均由当前数据支持，可直接用于下一教学阶段 |
| 专业准确与证据 | 至少 3 个关键数字经教师复算且最终完全一致，全部保留结论都有数据支持 |
| 人工核验与迭代 | 教师复核至少 3 个数字，同组成员复算至少 1 个；差异已纠正或记录确定性依据 |
| 隐私、版权、伦理与安全 | 只用匿名虚拟数据，无个人排名、固定能力、态度或歧视标签，分组边界明确 |

通关同时要求：总分不低于 8 分；四项核心步骤全部通过；专业准确与证据、人工核验与迭代、安全均为 2 分。初验和复验都保存不可变历史。

## 三、任务 M08：交互式教学网页生成与优化

### 1. 任务设计意图

**要解决的问题**：教师已有教案、检测题和课件后，仍需要把内容转化为学生可以直接操作、即时获得反馈且便于离线交付的网页，同时避免把 AI 原始结果未经测试就投入课堂。

**任务目标**：选择真实教学用途，生成规定结构的单文件网页，用自然语言完成两轮修改，在电脑和手机尺寸测试，再依据同组成员的学生操作修正至少一处。

**能力培养**：自然语言生成网页、交互设计、浏览测试、迭代修改。

### 2. 任务信息

| 标签 | 内容 |
| --- | --- |
| 编号 / 性质 / 难度 | M08 / 必修 / 应用 |
| 协作方式 | 个人主作、小组测试 |
| 教学场景 | 课堂互动、自主学习、闯关训练、课前预习 |
| 核心知识点 | 网页结构、交互反馈、多模态整合、离线交付 |
| 核心技能点 | 自然语言生成网页、交互设计、浏览测试、迭代修改 |

M08 可使用任务内已核验材料独立完成。M04 教案、M06 教师确认课件与讲解稿仅为可选复制来源，不构成进入或通关前置。

### 3. 平台需要提供的功能

1. 用途与输入：选择课堂互动、自主学习、闯关训练或课前预习，填写真实教学用途；可使用 M08 任务内材料，也可显式读取 M04 或 M06 当前成果。保存课程、课次、对象、学生基础、学习目标、材料和来源快照。
2. AI 原始网页：确定性本地生成标题、学习目标、3—5 张有材料依据的知识卡、恰好 5 道有答案/解析/依据的即时反馈题，以及至少 1 个点击、选择、排序、判断或分支互动。AI 原始 V0 只读保存。
3. 两轮迭代：教师逐轮填写自然语言修改指令，依次保存 V1、V2；每轮记录指令、修改前摘要、修改后摘要和版本编号，必须恰好 2 轮。
4. 下载与浏览测试：下载单文件 HTML；记录离线打开、电脑宽度、手机宽度、单文件、5 道题、即时反馈和互动操作的逐项检查。页面不得依赖外部资源。
5. 小组测试：只能从当前 `groupId` 选择其他 `participantId`，由组员以学生身份操作；记录操作过程、至少 1 个问题、修正前、修正后和依据。Demo 披露组员成果摘要为无多人后端的确定性模拟。
6. 教师确认：确认答案解析、材料一致性、响应式布局、离线安全和最终发布责任，形成教师最终网页。AI 原始内容、教师两轮修改和教师最终确认分别保存。
7. 评分归档：初验/复验历史不可覆盖；当前实质内容变化后旧历史保留但旧通过失效。任务内重置只清当前教师 M08，全局重置清全部教师。通过后成果中心只归档 `交互式教学网页` 1 个；两轮修改记录和小组测试记录属于该成果的任务内验收证据，不扩张个人成果类别。

### 4. 评分逻辑

| 任务过程质量标准 | 本任务 2 分要求 | 平台校验方式 |
| --- | --- | --- |
| 操作完成与核心步骤 | 单文件 HTML 可独立打开，至少 1 项互动有效，5 道题均可作答并获得即时反馈 | 校验完整 HTML、知识卡/题目数量、互动标识、下载及全部浏览测试、同组修正和当前教师确认 |
| 教学场景适配 | 网页内容、互动方式和难度符合教学目标、学生基础及使用环节 | 校验页面类型、用途、目标、对象、学生基础、互动路径和响应式教师确认 |
| 专业准确与证据 | 5 道题的答案、解析和即时反馈全部正确，并与已核验课程材料一致 | 校验 5 题均有合法答案、解析和依据，教师完成答案解析与材料一致性确认 |
| 人工核验与迭代 | 完成 2 轮自然语言修改，并根据小组测试再修正至少 1 处，保留记录 | 校验 V0/V1/V2、两条迭代记录、当前同组其他成员、问题及有前后差异的修正 |
| 隐私、版权、伦理与安全 | 不嵌入模型密钥、真实个人数据、未经授权资源或不安全操作内容 | 扫描输入和 HTML 中的密钥、真实联系方式、外链与网络请求，并校验版权/隐私/安全责任确认 |

通关同时要求：总分不低于 8 分；四项核心步骤全部通过；专业准确与证据、人工核验与迭代、隐私版权伦理安全均为 2 分。

## 四、任务 G02：多模态教学成果展示与互评

### 1. 任务设计意图

**要解决的问题**：小组成员的课件、数字人微课、互动网页和选修成果分散，单独展示无法说明连续教学用途，也容易遗漏学生体验、反馈修改和个人贡献。

**任务目标**：按成员目录聚合四类成果，编排一页式展示并在线操作至少一项网页互动，接收两条具体跨组反馈，完成一处修改并确认全员贡献。

**能力培养**：作品汇总、线上演示、同伴反馈、快速修改。

### 2. 任务信息

| 标签 | 内容 |
| --- | --- |
| 编号 / 性质 / 难度 | G02 / 阶段验收 / 应用 |
| 协作方式 | 小组共创 |
| 教学场景 | 作品展示、同伴反馈、课堂应用说明 |
| 核心知识点 | 多模态整合、学生体验、资源取舍 |
| 核心技能点 | 作品汇总、线上演示、同伴反馈、快速修改 |

G02 可独立进入和验收。当前教师已有 M06、M08 成果时优先读取；缺项仅在 G02 内使用明确标注的任务内演示成果，其他成员使用确定性模拟摘要，不反写个人任务。M07 不属于 G02 验收材料。首个选修成果读取第二天选修配置，未实现时使用明确标注的任务内演示项。

### 3. 平台需要提供的功能

1. 小组成果目录：按当前 `groupId` 列出每位成员的 M06 课件、M06 可播放视频、M08 互动网页和首个选修成果；逐项标记真实本地成果、任务内演示成果或模拟组员摘要。
2. 一页式展示：填写展示标题与统一教学场景，把四类成果按学习路径聚合到同一个展示页，完成小组确认。
3. 在线互动：从目录中的 M08 网页选择一项，记录现场操作的互动并确认已完成操作、看到即时反馈。
4. 跨组反馈：接收不少于 2 条来自不同于当前 `groupId` 的具体反馈。Demo 无多人后端时使用确定性跨组反馈并醒目标记，不冒充真实消息。
5. 反馈修改：选择一条反馈，记录修改前、修改后、依据、实际贡献成员和已应用状态；前后内容必须存在实质差异。
6. 成员贡献：当前组每位成员记录任务角色、作品贡献或实质修改、具体贡献和关联成果；全部成员确认后才满足条件。
7. 阶段验收：不采用 10 分制。允许保存未通过初验及失败条件；内容修改后状态进入需补验，补验填写修改摘要。人员目录、分组或实际成果来源变化后旧通过失效但历史保留。任务内重置只清当前小组 G02，全局重置清全部小组。

### 4. 评分逻辑

G02 不计数值分，四项验收条件必须同时通过：

| 验收条件 | 平台校验方式 |
| --- | --- |
| 成果展示页包含 AI 课件、可播放数字人微课视频、交互式教学网页和第一项选修成果 | 校验目录四类齐全、视频可播放标记、展示标题/场景、成果目录完整和小组确认 |
| 每位成员均有明确作品或修改贡献 | 按当前 roster 逐个校验角色、贡献类型、具体贡献和关联成果 |
| 至少 1 项互动可以在线完成 | 校验选择的目录项为 M08 互动网页、互动名称非空且现场测试已确认 |
| 收到不少于 2 条反馈，并完成至少 1 处修改 | 校验至少 2 条非当前组反馈，以及选用反馈、修改前后差异、依据、贡献者和已应用状态 |

只有四项全部通过才生成当前有效的 3 份成果；未通过不归档成果。
