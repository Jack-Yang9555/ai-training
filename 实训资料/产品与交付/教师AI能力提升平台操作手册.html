素养测评：建立教师 AI 能力基线

学校统一组织教师完成理论题、情境判断和实操任务，平台据此生成综合等级与五维能力证据，为分层培养提供依据。

教师端流程我的成长 → 摸底测评 → 完成三个部分 → 提交测评并生成报告
  1. 教师依次完成理论题、情境判断和实操任务，覆盖知识、场景判断与实践能力。
  2. 三个部分全部完成后提交测评，平台统一记录作答状态和评价证据。
  3. 系统生成综合等级、五维分数、优势证据、能力短板和推荐提升目标。
理论题：基础认知与安全情境判断：教学选择与风险实操任务：提示词与智能体
i
学校管理关注

应重点关注参测完成率、能力分布、共性短板和分层比例。题目、量规和能力标准由学校认可的外部内容体系导入，平台负责组织、记录与报告。

测评报告：形成分层培养决策依据

测评完成后，平台形成综合等级、五维能力、优势证据、优先补强方向和推荐目标，支持学校识别共性问题与教师差异。

报告结构综合等级 → 五维能力 → 证据说明 → 优先补强 → 推荐目标
个人层面

明确教师当前等级、优势领域和优先补强能力。

培训层面

将能力短板映射到必修课程、专项训练和实训任务。

学校层面

汇总教师能力分布，为分层分组和资源配置提供依据。

评价层面

与过程数据和结业复测对比，判断培训投入与能力变化。

学习培训：形成分层分类培养方案

平台结合教师摸底结果与学校已导入课程，生成个性化培训计划，兼顾统一必修要求与教师能力补弱需求。

教师端流程我的成长 → 培训计划 → 设置每周投入 → 调整顺序 → 确认并开始培训
  1. 教师查看方案状态、每周投入、预计周期和课程来源，确认计划可执行性。
  2. 在学校统一要求范围内调整学习顺序、投入时间和选修内容。
  3. 确认计划后进入执行阶段，平台持续记录计划完成情况。
✓
学校管理关注

学校应检查最低能力维度是否安排专项课程、公共必修是否全员覆盖，以及教师每周投入与校内教学工作节奏是否匹配。

第二步 · 学习培训（培训计划）06
2B

课程学习：记录全过程培训数据

课程学习工作区统一呈现视频、文档、案例和实训资源，并记录教师进度、收藏、笔记与资源完成情况。

教师端流程培训计划 → 继续课程学习，或 我的成长 → 课程学习
  1. 教师依据个人培训计划进入相应课程资源，完成视频、文档、案例或实训学习。
  2. 学习过程中的进度、收藏和笔记形成过程性培训记录。
  3. 资源完成状态同步回流培训计划和个人能力档案，为过程评价提供数据支持。

实训任务：推动 AI 能力向工作场景迁移

任务地图围绕知识底座、AI 助教、命题组卷和批改分析四条能力链，组织十一项与教师实际工作相关的实践任务。

教师端流程我的成长 → 实训记录 → 进入自由实训 → 培训任务地图
  1. 教师依据四条能力链和任务前置关系，选择已经解锁的实践任务。
  2. 任务原则上使用本人的课程资料、教案、量规或真实教学问题作为输入。
  3. 任务成果自动进入个人成长档案，并可进一步沉淀为学校校本案例与资源资产。

第三步 · 实训任务（任务地图）08
3B

工具实训：支撑教师开展自主实践

工具广场覆盖研究、多模态、知识库、智能体、开发与评测等十三类 AI 能力，为教师提供统一实践环境。

教师端流程自由实训 → 工具广场 → 选择工具 → 设置难度与时长 → 开始自由实训
  1. 教师按能力分类筛选工具，并结合岗位任务选择推荐起步任务。
  2. 根据个人基础选择难度和练习时长，形成可执行的实践安排。
  3. 完成实训后，平台自动记录工具、任务、时长、得分和作品。
✓
学校管理关注

自由实训不纳入课程成绩，但其任务完成、作品质量和能力证据可用于评价教师实践参与度与工作迁移成效。

分析报告：形成教师成长与项目成效证据

能力报告汇总摸底结果、课程进度、实训成果和科研智能体等证据，持续呈现五维能力变化，为学校评价培训成效提供依据。

教师端流程我的成长 → 能力报告 → 查看五维变化 → 完成下一任务或参加结业复测
  1. 报告呈现教师当前能力等级及课程、实训、研究等成果证据。
  2. 通过“摸底 → 当前”的五维变化，识别个人进步与仍需补强的能力。
  3. 完成培训后参加结业复测，形成阶段性或结业发展结论。

项目评价不宜只看综合等级，应综合五维变化、任务完成、成果质量、人工复核与工作迁移情况，形成学校层面的后续培养决策。

校级实施验收与管理要点

学校可依据以下事项检查项目组织、教师参与、数据沉淀与成效评价是否形成完整闭环。

✓参训教师已按要求完成摸底测评
✓学校已掌握五维能力基线与分布
✓分层培训计划已经确认并执行
✓课程学习过程数据持续记录
✓教师完成与岗位相关的真实任务实训
✓实训成果已回流个人成长档案
✓学校已形成阶段性项目成效分析
✓满足条件的教师已完成结业复测
管理情形建议措施
测评完成率不足明确参测范围和完成时限，并按组织或学科跟踪完成情况。
培训计划尚未形成先完成摸底报告，再依据能力差异生成并确认培养方案。
课程参与度偏低结合教学工作安排优化学习节奏，并关注进度、笔记和资源完成数据。
实训任务推进缓慢检查前置任务与输入材料，优先组织低门槛、高频工作的示范任务。
能力变化不明显增加真实任务、成果复核和岗位应用证据，再开展阶段复测。
需要现场汇报演示使用“重置演示”恢复初始状态，并按四步路径完整展示。
