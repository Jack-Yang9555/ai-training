# 高职教师 AI 实操培训执行指南
### 面向：课程主讲 / 辅导教师 / 平台支持人员 / 培训管理人员

> 本指南旨在帮助一线培训人员和管理人员在不阅读完整技术方案的情况下，明确**每个环节的职责、操作方式和完成标准**。完整的任务规则和评分细则以平台内《高职教师AI实操培训三日方案》第七部分为准，本指南仅作执行速查。

---

## 一、角色与分工

| 角色 | 主要职责 |
| --- | --- |
| **组织方 / 培训管理人员** | 开班前准备、分组、账号开通、测评组织、进度监督、异常处理决策、最终成果认证审核 |
| **课程主讲** | 录制/审核任务视频、开班前汇总测评结果并调整讲解深度、在线答疑 |
| **辅导教师（2名）** | 通过平台和微信群在线巡查答疑、跟踪学员进度、通过微信群发放小组核验在线文档并回收数据、组织三次阶段验收、记录评分与复验 |
| **平台支持人员** | 保障账号、工具、视频播放、渲染队列等平台功能可用，处理技术故障 |
| **学员（教师）** | 完成个人实操任务，参与小组核验与协作 |

## 二、开班前：管理人员和课程主讲须完成的事项

开班前，以下事项须**全部确认完成**，否则不具备开班条件：

- [ ] 完成分组（每组4—6人，AI基础和专业背景混合编组，三天固定不变）
- [ ] 确定首日角色安排（协调员/操作员/核验员/记录员/展示员，6人组另设学生体验员）
- [ ] 开通全部学员账号，确认可登录、可用实训工具
- [ ] 通知学员完成**培训前AI认知测评**（见第三节），并回收测评报告
- [ ] 汇总全班测评的五维得分均值和短板分布
- [ ] 平台发布全部任务教学视频、教学任务
- [ ] 通知每位教师提前准备好本人一门课程的非敏感材料（课程名称/对象/主题、课程目标节选、2—5份讲义或任务书、一份原教案或课件用于修改前后对比）
- [ ] 建立培训微信群和各小组微信群，确认全体学员和辅导教师均已入群

**完成标志**：以上全部打勾，方可视为具备开班条件。

## 三、培训前测评组织

| 项目 | 说明 |
| --- | --- |
| 通知发送 | 组织方在开班前通知学员 |
| 测评工具 | 默认使用"Demo固定30题卷"（单文件交互页面，本机保存），约30分钟 |
| 填写内容 | 姓名、院系、手机号（必填，用于登记）；年龄、工号选填，且不作为评价依据 |
| 报告接收方 | 学员本人获得个人测评报告（总分、等级L1—L4、五维得分、安全题表现）；课程主讲获得全班汇总数据（五维均分、短板分布） |
| 注意事项 | 安全相关题得分低于60%时单独标注"安全规范优先补强"，该标注不受总分影响，课程主讲须在视频讲解中针对性强化 |

**完成标志**：全部学员在开班前完成测评并生成个人报告；课程主讲已拿到全班汇总数据并据此确定第一天视频讲解的深度和节奏。

> 测评结果不用于排名或淘汰，只用于确定培训起点和后续对照，不计入三天培训的100分总评。

## 四、三天培训期间：辅导教师和管理人员的常规工作流程

不论具体任务是什么，**每一项必修和选修任务均按统一四步流程执行**，辅导教师据此流程在线巡查：

1. **视频学习**：学员看该任务配套的5—10分钟视频（背景与用途→操作演示→达标条件和常见问题）
2. **个人完成**：学员用本人课程材料，在平台上操作，形成个人成果
3. **小组核验**：辅导教师通过微信群发放该任务的小组核验在线文档，组内成员互相依据任务专用标准检查事实、专业内容、教学适用性、安全边界，填写完成后在线提交
4. **修改验收**：学员根据反馈修改，保留修改前后记录，再提交验收

**辅导教师在每项任务中的工作内容：**
- 通过平台查看学员视频观看记录，对未观看视频或进度明显滞后的学员通过微信群主动提醒
- 通过平台和微信群在线解答操作性问题，不代替学员完成核验和修改
- 在微信群发放小组核验在线文档，回收核验数据并核查填写质量
- 在三次阶段验收点组织学员按验收清单逐项核查
- 记录评分：初评分、修改内容、复验分、验收人——**不得直接覆盖初评分**，未通过项须保留问题记录，修改后复验

## 五、三天日程与任务安排

> 学员按以下顺序逐项完成任务，**提前完成当前任务的学员可自行进入下一个任务，也可提前进入次日的任务**，不必等待统一时间节点。辅导教师通过平台和微信群跟踪进度，阶段验收时间固定不变。

### 第一天：AI可信使用、教学设计与命题

1. 大模型幻觉识别与内容核验
2. 多模型结果对比与选择
3. 结构化提示词设计与迭代
4. AI辅助教案编制
5. AI辅助命题与审校
6. **第一天阶段验收：教学设计与命题成果验收**（辅导教师组织）

### 第二天：多模态教学资源、学情分析与成果展示

1. AI课件与数字人微课制作
2. AI辅助成绩分析与分层教学
3. 交互式教学网页生成
4. 第一项选修（从选修任务中任选1项，小组统一选择）
5. **第二天阶段验收：多模态教学成果展示与互评**

### 第三天：课程知识库、AI助教与综合应用

1. 课程知识库建设与测试
2. 课程AI助教配置
3. 学生答疑功能测试与优化
4. 第二项选修（与第一天选修不同的一项）
5. AI教学成果综合应用
6. **第三天阶段验收：课程知识库与AI助教综合测试及展示（结业展示）**

## 六、选修任务（小组统一选择2项，个人分别完成）

各组从以下6项中共同选择2项，第一项安排在第二天，第二项安排在第三天。管理人员须在**第二天开始前**确认各组已选定组合和顺序。**两项成果均须由每位教师独立完成个人版本。**

1. AI辅助批改与个性化反馈
2. 实训任务书与评分量规设计
3. AI辅助教学反思与评课
4. AI辅助课程知识图谱设计
5. 课程目标与岗位能力映射网页
6. 教研文献梳理与引用核验

## 七、成果提交后：总分计算与等级认定

### 1. 总分构成（100分）

| 板块 | 分值 | 算法 |
| --- | ---: | --- |
| 12项必修任务 | 60分 | 12项原始分合计 ÷ 2 |
| 2项选修任务 | 10分 | 2项原始分合计 ÷ 2 |
| 10类个人成果综合评分 | 20分 | 成果原始分（10分制）× 2 |
| 小组协作表现 | 10分 | 协作原始分（10分制），按个人记录评，不用组平均分代替 |

### 2. 达标条件（须同时满足）

1. 总分（未四舍五入）≥ 80分
2. 12项必修任务和本人所选2项选修任务，每项都≥8分，且通过全部核心步骤要求
3. 10类个人成果原始分≥8分，且"专业准确与证据/人工核验与迭代/隐私版权伦理安全"三项都是满分
4. 小组协作表现≥8分
5. 三次阶段验收全部验收条件通过

**任一条不满足者，状态为"待补验"，须修改后补验，不得按当前分数直接认定结果。补验时初验分、修改内容、复验分须全部保留，不得覆盖。**

### 3. 成果认证等级（供管理人员最终审核）

| 等级 | 总分区间 | 前提条件 |
| --- | --- | --- |
| 待补验 | <80.0分，或任一达标条件未通过 | — |
| AI教学实操达标 | 80.0—89.9分 | 全部达标条件通过 |
| AI教学综合应用良好 | 90.0—94.9分 | 全部达标条件通过 |
| AI教学综合应用优秀 | 95.0—100.0分 | 全部达标条件通过 |

成绩展示保留1位小数，等级判定使用未四舍五入的原始总分。选修成绩仅用于判断本人是否达标，不同选修任务之间不进行横向排名。

## 八、个人最终成果记录（结业时管理人员须核对完整）

每位学员结业档案须包含以下8项，缺任一项视为记录不完整：

- [ ] 综合成果等级（总评、认证等级、初验/补验状态）
- [ ] 已取得能力成果（按AI基础认知/提示词与多模态/知识库与智能体/教学融合/研究创新五个维度，只记已达标的）
- [ ] 拓展方向（本人选择的2项选修任务及成果；未涉及"研究创新"方向的写明"本期未选择该拓展方向"，不算能力不足）
- [ ] 10类个人成果逐项登记（名称/版本/完成状态，见下表）
- [ ] 2项代表作（从不同任务类型中选择完成质量较高、可在线打开或演示的）
- [ ] 至少1个完整的"AI草稿—发现问题—教师修改—修改依据"案例
- [ ] 小组贡献记录（角色、交叉核验、实际操作、讲解、协作修改）
- [ ] 三次阶段验收成果的通过状态和本人贡献

**10类个人成果清单：**

| 序号 | 成果 | 来源任务 |
| --- | --- | --- |
| 1 | 教师教案 | AI辅助教案编制 |
| 2 | 课堂题目包 | AI辅助命题与审校 |
| 3 | AI课件与数字人微课成果 | AI课件与数字人微课制作 |
| 4 | 学情分析与分层学习任务 | AI辅助成绩分析与分层教学 |
| 5 | 交互式教学网页 | 交互式教学网页生成 |
| 6 | 课程知识库和来源清单 | 课程知识库建设与测试 |
| 7 | 课程AI助教 | 课程AI助教配置 |
| 8 | 学生答疑测试与复测记录 | 学生答疑功能测试与优化 |
| 9 | 第一项个人选修成果 | 选修任务之一 |
| 10 | 第二项个人选修成果 | 选修任务之一 |

> 注：第一天的核验记录、模型对比、提示词迭代属于"过程性成果"，单独保留，不计入这10类。AI教学成果综合应用不产生新成果类别，只产出成果目录、使用说明和人工修改记录，用于整合以上10类。

## 九、异常情况处理速查（供辅导教师/平台支持人员在线使用）

| 异常情况 | 处理方式 |
| --- | --- |
| 学员未准备课程材料 | 使用培训方提供的虚构专业案例，不影响验收 |
| 教学视频无法播放或加载缓慢 | 提供离线下载版；辅导教师在微信群发布文字版操作步骤作为替代 |
| 网络或模型临时不可用 | 使用预生成结果继续核验和修改，恢复后在该任务对应的阶段验收前补做本人模型调用 |
| PPT生成/导出失败 | 使用备用PPT模板继续修改内容，恢复后在第二天阶段验收前补做生成和导出并保留记录 |
| 数字人/视频渲染时间过长 | 使用低清预览继续核验，正式视频后台渲染，第二天阶段验收前须形成可播放预览 |
| 文档解析/知识库索引失败 | AI辅助教案编制和AI辅助命题与审校的解析须在第一天阶段验收前补做；课程知识库建设、课程AI助教配置和学生答疑功能测试的索引、测试和复测须在第三天阶段验收前补齐 |
| 网页生成/下载失败 | 使用离线单文件模板继续修改和测试，第二天阶段验收前形成可离线打开的个人成果 |
| 平台成果记录系统故障 | 核验员和辅导教师使用电子表格记录，保留验收人和复验结果，通过微信群收集数据，事后补录平台 |
| 学员进度明显滞后 | 辅导教师通过微信群主动联系，提供一对一在线辅导或调整当日任务顺序 |

**总原则：所有备用流程均须保留学员的实际操作、核验和修改记录，不得以预生成结果直接代替个人成果。**

## 十、待管理人员补充明确的事项

以下内容在原方案中未提供可直接执行的操作细则，管理人员须在正式开班前自行明确：

- **培训结束后的班级/项目级分析报告**：由谁负责产出（建议课程主讲或平台支持人员）、须包含哪些内容（如全班测评前后五维对比、各任务通过率、返工比例、成果认证等级分布、安全项预警统计、下一期改进建议）、产出时间节点和报送对象。目前方案仅覆盖"个人最终成果记录"层面，尚无面向管理层的汇总报告规则。
